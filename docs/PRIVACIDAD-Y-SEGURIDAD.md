# Privacidad y seguridad

PFMEA Flow v0.4.1 es una aplicación estática sin backend.

- Los proyectos se guardan en el navegador del usuario.
- La aplicación no incluye analytics ni telemetría.
- No envía proyectos a GitHub ni a servicios de terceros.
- El service worker solo solicita recursos del mismo origen.
- Las exportaciones se generan localmente.
- El sitio público incluye únicamente un ejemplo genérico.

Esto no convierte al navegador en un QMS validado ni en un repositorio documental. El acceso al equipo, el perfil del navegador, las copias externas y el tratamiento de información confidencial siguen sujetos a las políticas de la organización.
