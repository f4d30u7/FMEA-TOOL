# Uso con proyectos reales

## Reglas operativas mínimas

- Abrir siempre la misma URL y el mismo perfil del navegador.
- No utilizar navegación privada o incógnito.
- Exportar el proyecto `.pfmea.json` al terminar cada sesión importante o reunión de equipo.
- Guardar el respaldo en una ubicación corporativa aprobada, con código y revisión.
- Generar Excel o PDF para revisión documental, pero conservar también el JSON editable.
- No limpiar datos del navegador antes de verificar que existen respaldos externos.
- No trabajar simultáneamente sobre el mismo proyecto en dos pestañas o dispositivos.

## Qué queda en GitHub

Solo queda el código genérico de la aplicación. Los PFMEA creados se guardan localmente en IndexedDB y no se envían al repositorio.

## Qué puede hacer perder datos

- Borrar datos del sitio o del navegador.
- Cambiar de navegador o de perfil.
- Usar otra computadora.
- Cambiar la URL del sitio.
- Políticas corporativas que purguen almacenamiento local.
- Daño o reemplazo del equipo.

Por eso el respaldo JSON externo no es opcional para trabajo real, por más que los navegadores disfruten presentándose como eternos.
