# PFMEA Flow v0.4.1 · GitHub Pages

Parche de publicación sobre la v0.4 funcionalmente aprobada.

## Cambios

- Workflow oficial de GitHub Pages mediante GitHub Actions.
- Sitio aislado dentro de `site/`.
- Ejemplo demostrativo completamente genérico.
- Eliminación de referencias al proyecto Guardian en la edición pública.
- Validación automática contra términos reservados.
- Rutas relativas compatibles con sitios de proyecto.
- Service worker ajustado para actualizar navegaciones y funcionar offline.
- Metadatos `noindex`, política CSP y bloqueo de referencias externas.
- Guías de deployment, respaldo y privacidad.

No se modificó la metodología PFMEA ni la experiencia Lean UX aprobada.
